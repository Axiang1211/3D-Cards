# 3D Cards

把照片做成會反光的 3D 鐳射卡片。

上傳一張照片，選一種鐳射效果，卡片就會跟著滑鼠傾斜、跟著手機轉動，光澤會隨著角度流過整張卡片。

**線上使用：https://3dcards.app.dreamsworld.top/**

**下載 App：https://3dcards.app.dreamsworld.top/#/download**
（Windows、Mac、Android；iPhone 版即將推出）

**Windows App：[下載 3D-Cards-Setup.exe](https://github.com/Axiang1211/3D-Cards/releases/latest/download/3D-Cards-Setup.exe)**　**Mac App：[下載 3D-Cards.dmg](https://github.com/Axiang1211/3D-Cards/releases/latest/download/3D-Cards.dmg)**　**Android App：[下載 3D-Cards.apk](https://github.com/Axiang1211/3D-Cards/releases/latest/download/3D-Cards.apk)**　**iPhone / 其他：把網站安裝成 App**（見下方）

不用註冊，打開網頁就能做。介面有中文和 English，在頁面最下方切換。照片只在你的裝置上處理，只有你按下「分享」的卡片才會上傳。

## 怎麼做一張卡片

1. 打開網站，按右上角的 **製作卡片**
2. 按 **選擇照片**，或直接把照片拖進預覽區
3. 在 **背景照片** 用縮放、水平位置、垂直位置調整照片要露出的部分
4. 在 **背景鐳射** 選樣式和範圍，再用 **強度**、**紋理大小**、**色調** 微調
5. （選用）加入 **前景圖層**，見下方說明
6. 填上 **標題**、**副標**、**編號**（都可以留空），選擇 **邊框**，以及卡片背面的 Logo 要用 **原圖** 還是 **黑白漫畫** 風格
7. 按 **儲存到展廳**

左邊的預覽會即時變化，把滑鼠移上去就能看到鐳射效果。每一組設定都有「重設」按鈕可以回到預設值。

做好的卡片會出現在首頁展廳的「我的卡片」裡。

### 鐳射樣式

| 樣式 | 效果 |
| --- | --- |
| 彩虹 | 斜向的彩虹光帶加上細密的繞射紋 |
| 星塵 | 細碎的亮片，傾斜時會一閃一閃 |
| 稜鏡 | 一圈圈的光環，顏色隨角度旋轉 |
| 流光 | 拉絲金屬的質感，一道光帶掃過 |
| 亮面 | 沒有彩色鐳射，只有光滑的反光 |

**範圍** 可以選整張卡片、只有照片，或只有邊框。

| 數值 | 作用 |
| --- | --- |
| 強度 | 鐳射有多明顯，0% 是沒有，100% 是預設，最高 200% |
| 紋理大小 | 條紋、亮片、光環的大小 |
| 色調 | 把整組顏色往色環的另一邊轉，例如讓彩虹偏藍或偏粉 |

### 讓卡片更立體：前景圖層

在 **前景圖層** 加一張去背的 PNG（例如把照片裡的人物去背），它會浮在照片上方。傾斜卡片時，前景和背景會往不同方向移動，看起來就像有深度。

加入前景後可以：

- 用 **前景大小**、**前景左右**、**前景上下** 單獨調整前景的位置
- 給前景 **不同的鐳射**（例如背景彩虹、人物星塵），或選「無」讓人物保持原色，再調整前景鐳射的強度和色調
- 用 **背景模糊** 把背景照片變模糊，讓前景更突出

用和原照片一樣大的去背圖，位置一開始就會對齊。

**自動摳圖**：沒有去背圖的話，按 **從照片自動摳圖**，電腦會在你的裝置上把照片裡的主體摳出來當前景，照片不會上傳。主體清楚、背景單純的照片效果最好，不保證每張都摳得乾淨；不滿意的話可以用手機相簿的「拷貝主體」或 remove.bg 之類的網站去背後再上傳。第一次使用要下載約 8 MB 的工具。

### 流沙

加入前景後，勾選 **流沙**，背景和前景之間會出現一層泡在透明油裡的細沙：慢慢沉下去、轉動時會帶著慣性繼續流動，亮片會隨著角度閃光。沙的數量（畫面的 10%–80%）、顆粒大小和顏色都可以自己調。

- 沙子永遠往下流，堆在底部
- 按 **上下顛倒**，卡片會轉 180°，沙子就倒向另一邊
- 在手機上，沙子會跟著手機的傾斜方向流動；手機平放時沙子會停住

## 怎麼把玩卡片

| | 電腦 | 手機 |
| --- | --- | --- |
| 傾斜 | 滑鼠在卡片上移動 | 轉動手機，或用手指拖曳卡片 |
| 翻面 | 點一下卡片 | 點一下卡片 |
| 換上一張／下一張 | 按 `[` `]` 鍵，或按右上角的 ‹ › | 在卡片旁邊的空白處左右滑動 |
| 全螢幕 | 按 **全螢幕**，拖曳往任何方向 360° 旋轉（放開後停在哪就是哪，流沙會往畫面下方流）、按 **360° 自動旋轉** 讓卡片轉不停、雙擊翻面、滾輪縮放，按 Esc 離開 | 按底部的 **全螢幕**，拖曳 360° 旋轉、點兩下翻面、雙指縮放，傾斜手機會有立體感 |

手機上，**分享**、**全螢幕**、**翻面** 等按鈕固定在畫面底部。

**iPhone 和 iPad**：第一次要按 **用手機轉動卡片**，再在跳出的視窗按「允許」，卡片才會跟著手機動。

**卡片歪一邊？** 按 **重新校正水平**，卡片會以你現在拿手機的角度當作平放。

## 保存和分享你的卡片

做好的卡片存在 **你目前使用的瀏覽器** 裡，所以要注意：

- 換一台裝置、換一個瀏覽器，或用無痕模式，都看不到之前做的卡片
- 清除瀏覽器的網站資料，卡片會一起被刪掉

### 分享連結

打開卡片，按 **分享**，再按 **建立分享連結**，就會得到一個像 `https://3dcards.app.dreamsworld.top/s/AbCd1234` 的網址。把它傳給朋友，對方點開就能直接看到並轉動這張卡片，也可以按「存到我的卡片」收藏。貼到 LINE、Discord、Facebook 等地方時會顯示卡片照片的預覽。

- 建立連結時，這張卡片的照片會上傳到網站的伺服器
- **連結會保留 14 天**，之後自動失效，照片也會從伺服器刪除。想讓別人一直看得到，請對方按「存到我的卡片」，或傳卡片檔給他
- 連結過期後，在原本的卡片再按分享，就能建立新的連結
- 同一張卡片在 14 天內再按分享，會得到同一個連結
- 編輯過卡片再分享，會產生新連結，舊連結自動失效
- 在分享視窗按 **停止分享**，連結會立刻失效

### 收下別人分享的卡片

別人傳分享連結給你時，除了直接點開，也可以在展廳按 **用連結加入**，把連結貼上，卡片就會存進「我的卡片」，連結過期後也看得到。

### 卡片檔（.3dcard）

1. 打開卡片，按 **下載卡片檔**，會得到一個 `.3dcard` 檔案（照片也包含在裡面）
2. 在任何裝置打開網站，到首頁展廳按 **匯入卡片檔**，選這個檔案
3. 有安裝 Windows 或 Mac 電腦版的話，**直接雙擊 `.3dcard` 檔** 就會用 3D Cards 打開並加入卡片

同一個檔案匯入兩次不會變成兩張。舊版的 `.holocard.json` 也可以匯入。

### 用 Google 帳號同步

在展廳按 **用 Google 同步**，登入 Google 後按 **立即同步**，卡片會存到你自己的 Google 雲端硬碟（一個只有 3D Cards 看得到的隱藏資料夾）。在另一台電腦、手機或電腦版登入同一個帳號再同步，卡片就會出現。

- 改過的卡片以最新的那份為準
- 在一台裝置刪掉的卡片，同步後也會從雲端和其他裝置的下次同步中移除
- 電腦版登入時會自動打開你的瀏覽器，核對畫面上的確認碼後登入 Google 即可

### 公開展廳

**公開展廳**（網站上方的選單，或 App 的「展廳」）展示大家分享的卡片，可以切換 **綜合推薦**、**最高讚**、**最新**。每張卡片會顯示作者的公開名稱、讚數和公開日期。

- **按讚 / 倒讚**：用 Google 登入後，打開別人的卡片按 👍 或 👎，再按一次可以取消。不能替自己的卡片投票
- **公開自己的卡片**：打開你的卡片按 **公開到展廳**（或在公開展廳按 **公開我的卡片**）。第一次會請你設定 **公開名稱**，展廳只顯示這個名稱，不會顯示你的 Google 帳號或信箱。送出後由管理員審核，通過後才會出現
- 送出時要選一個說明：**原創**（照片是你拍攝或創作的，或你有權公開）或 **轉載**（你分享的公開照片，版權方要求時願意下架）。展廳和卡片頁都會標示「原創」或「轉載」
- 首頁的展廳可以切換 **全部／示範／公開／我的**，「公開」顯示公開展廳裡的卡片
- 卡片頁會顯示審核狀態；審核中可以取消，公開後也可以隨時下架
- **審核中或已公開的卡片不能直接修改**：按「編輯」會另存成一張新卡片，公開的那張不變。想改原卡片，要先取消送審或下架（管理員下架後也可以）
- **別人的公開作品**：照片不能編輯或再次公開，但可以按 **用這組參數製作**，沿用它的鐳射、邊框和流沙設定，換上自己的照片做成新卡片
- **用這組參數製作**：喜歡的公開卡片不能存成自己的卡片（照片屬於作者），但可以沿用它的設定，換上自己的照片

展出的作品由使用者分享，版權屬於原作者。若有版權爭議，請寫信到 [axianggaming1211@gmail.com](mailto:axianggaming1211@gmail.com) 聯繫刪除。

### 隱形水印

建立分享連結或送到公開展廳時，照片會加上肉眼看不見的水印，記錄是誰上傳的（公開名稱加一組代號；沒有登入時是 `unknown user`）。

- 別人的卡片導入到你這裡時（分享連結、卡片檔、公開展廳），**水印不會改成你的名字**
- 只有原本的水印是 `unknown user` 時，導入時才會換成導入者（已登入）的名字
- 照片被縮放或裁切後，水印就讀不到了

## 安裝成 App

3D Cards 有四種 App，介面都一樣：深色的卡片庫，電腦上左邊是側邊欄，手機上下方是分頁列。分成「我的卡片」「示範作品」「製作卡片」「設定」；在卡片上按右鍵（手機長按）可以快速打開、分享、匯出、編輯或刪除。

### Windows

1. 下載 [3D-Cards-Setup.exe](https://github.com/Axiang1211/3D-Cards/releases/latest/download/3D-Cards-Setup.exe)，或到這個 GitHub 頁面右側的 **Releases** 下載
2. 雙擊執行，照著畫面安裝，桌面會出現 3D Cards 的圖示

第一次執行時，Windows 可能會顯示「Windows 已保護您的電腦」。這是因為程式沒有購買數位簽章，按 **其他資訊**，再按 **仍要執行** 就能安裝。電腦版使用 Windows 內建的 Edge 瀏覽器核心（WebView2），少數電腦沒有的話，安裝程式會自動下載。

快速鍵：`Ctrl+N` 製作卡片、`Ctrl+O` 匯入卡片檔、`Ctrl+F` 搜尋、`Ctrl+,` 設定、`Ctrl+S` 儲存卡片；看卡片時 `←` `→` 換卡、空白鍵翻面、`F` 全螢幕、`E` 編輯、`Delete` 刪除、`Esc` 返回。

### Mac

1. 下載 [3D-Cards.dmg](https://github.com/Axiang1211/3D-Cards/releases/latest/download/3D-Cards.dmg)，或到這個 GitHub 頁面右側的 **Releases** 下載
2. 打開 `3D-Cards.dmg`，把 **3D Cards** 拖到 **應用程式** 資料夾
3. 從「應用程式」或 Launchpad 打開 3D Cards

支援 macOS 10.15 以上，Apple 晶片（M1 以後）和 Intel 的 Mac 都可以用同一個檔案。

第一次打開時，Mac 可能會說「無法打開」或「無法驗證開發者」。這是因為程式沒有購買 Apple 的開發者簽章：到 **系統設定** → **隱私權與安全性**，往下捲到底按 **仍要打開**，之後就能正常打開。

快速鍵和 Windows 一樣，把 `Ctrl` 換成 `⌘`。

### Android

1. 用手機下載 [3D-Cards.apk](https://github.com/Axiang1211/3D-Cards/releases/latest/download/3D-Cards.apk)
2. 打開下載的檔案。第一次會問要不要允許瀏覽器「安裝不明來源的應用程式」，允許後再按 **安裝**
3. 主畫面會出現 3D Cards

這個 App 不在 Play 商店上，所以手機可能會提醒「來源不明」，這是正常的。

### 把網站安裝成 App（iPhone、Android、電腦都可以）

- **Android（Chrome）**：打開網站，按右上角 ⋮ →「安裝應用程式」，或網站上方的 **安裝 App**
- **iPhone / iPad（Safari）**：打開網站，按下方的「分享」→「加入主畫面」
- **電腦（Chrome / Edge）**：按網址列右邊的「安裝」圖示

安裝後從主畫面或桌面打開，就會是 App 的樣子，沒有網路也能看你的卡片。網站更新時，App 會自動跟著更新。

### 更新

Windows、Mac 和 Android App 每次打開都會到 GitHub 檢查有沒有新版本。有的話會問你要不要更新：

- **下載新版**：下載新的安裝檔，安裝後就會換成新版本，做過的卡片都會保留
- **稍後再說**：繼續使用目前的版本，但不會有新功能
- 勾選 **這個版本不再提醒**，直到下一個新版本推出前都不會再問

也可以隨時在 App 的 **設定** → **檢查更新**。

每個 App 和瀏覽器的卡片是各自保存的。要在裝置之間搬移，用 **雲端同步**，或「匯出卡片檔」和「匯入卡片檔」。

### 把自己的卡片放進示範展廳

示範展廳的卡片每個人都看得到。要加入一張：

- **用腳本**：`node scripts/add-card.mjs 你的卡片.holocard.json --id my-card`，會自動把圖片放進 `public/gallery/`，並更新 `gallery.js`
- **手動**：把照片放進 `public/gallery/`，再照 `gallery.js` 開頭的說明加一筆資料

### 調整或新增鐳射效果

所有鐳射都寫在 `css/holo-card.css` 的 Foil 區段。卡片每一格畫面都會更新這些 CSS 變數，鐳射圖樣只要拿它們來畫：

| 變數 | 意義 |
| --- | --- |
| `--rx` `--ry` | 卡片的傾斜角度 |
| `--mx` `--my` | 光源位置（0%–100%） |
| `--dx` `--dy` | 指標離中心多遠（-1 到 1），用來做視差 |
| `--bgx` `--bgy` | 鐳射圖樣的位置 |
| `--o` | 鐳射強度（0–1），傾斜越大越亮 |
| `--k` `--sc` `--hue` | 每一層鐳射自己的強度、紋理大小、色調（來自卡片設定） |

鐳射分成三層：照片上的背景鐳射（`.hc__foil--art`）、邊框上的背景鐳射（`.hc__foil--frame`）、依照前景形狀遮罩的前景鐳射（`.hc__foil--fg`）。

新增一種鐳射：在 `js/holo-card.js` 的 `HC.FOILS` 加一筆，再寫一段 `.hc__foil[data-foil="名稱"] { … }`。

### 在其他網頁使用卡片元件

只需要 `css/holo-card.css`、`js/motion.js`、`js/holo-card.js` 三個檔案：

```html
<link rel="stylesheet" href="holo-card.css">
<script src="motion.js"></script>
<script src="holo-card.js"></script>

<div id="slot" style="width: 300px"></div>
<script>
  const card = new HC.HoloCard(
    { image: "photo.jpg", title: "標題", foil: "prism", frame: "white" },
    { flippable: true, dragTilt: true }
  );
  document.getElementById("slot").appendChild(card.el);
</script>
```
