# 3D Cards

把照片做成會反光的 3D 鐳射卡片。

上傳一張照片，選一種鐳射效果，卡片就會跟著滑鼠傾斜、跟著手機轉動，光澤會隨著角度流過整張卡片。

**👉 線上使用：https://3dcards.app.dreamsworld.top/**

免費、不用註冊，打開網頁就能做。介面有中文和 English。照片只在你的裝置上處理，只有你按下「分享」或「公開」的卡片才會上傳。

## 三步做一張卡片

1. 按 **製作卡片**，選一張照片（或直接拖進預覽區）
2. 選一種 **鐳射效果**，填上標題、選邊框
3. 按 **儲存到展廳**，卡片就會出現在「我的卡片」

做的時候把滑鼠移到預覽上，就能看到鐳射效果。每組設定都有「重設」可以回到預設值。

### 鐳射效果

| 樣式 | 效果 |
| --- | --- |
| 彩虹 | 斜向的彩虹光帶加上細密的繞射紋 |
| 星塵 | 細碎的亮片，傾斜時一閃一閃 |
| 稜鏡 | 一圈圈的光環，顏色隨角度旋轉 |
| 流光 | 拉絲金屬的質感，一道光帶掃過 |
| 亮面 | 沒有彩色鐳射，只有光滑的反光 |

鐳射可以只放在照片、只放在邊框，或整張都有；也可以調整 **強度**、**紋理大小** 和 **色調**。

### 讓卡片更立體

- **前景圖層**：加一張去背的人物或物品，它會浮在照片上方，傾斜時前後分開移動，看起來有深度。前景可以有自己的鐳射，也可以讓背景變模糊
- **自動摳圖**：沒有去背圖的話，按 **從照片自動摳圖**，會在你的裝置上把主體摳出來，照片不會上傳。主體清楚、背景單純的照片效果最好
- **流沙**：在前景和背景之間加一層會流動的亮片細沙，轉動卡片時沙子跟著流，數量、大小和顏色都能調

## 把玩卡片

| | 電腦 | 手機 |
| --- | --- | --- |
| 傾斜 | 滑鼠在卡片上移動 | 轉動手機，或用手指拖曳 |
| 翻面 | 點一下卡片 | 點一下卡片 |
| 換卡片 | `[` `]` 鍵（App 也可以用 `←` `→`），或右上角的 ‹ › | 在卡片旁左右滑動 |
| 全螢幕 | 拖曳 360° 旋轉、滾輪縮放、雙擊翻面，Esc 離開 | 拖曳旋轉、雙指縮放、點兩下翻面 |

- **iPhone / iPad**：第一次要按 **用手機轉動卡片**，再按「允許」，卡片才會跟著手機動
- **卡片歪一邊？** 按 **重新校正水平**，以你現在拿手機的角度當作平放

## 保存和分享

你的卡片存在 **目前使用的瀏覽器或 App** 裡。換裝置、換瀏覽器、用無痕模式，或清除網站資料，都會看不到之前的卡片，所以建議開啟 Google 同步，或定期下載卡片檔備份。

| 方式 | 怎麼用 |
| --- | --- |
| **分享連結** | 打開卡片按 **分享** → **建立分享連結**，朋友點開就能轉動卡片，也能存進自己的收藏。連結保留 14 天，可以隨時停止分享 |
| **卡片檔（.3dcard）** | 按 **下載卡片檔**，在任何裝置按 **匯入卡片檔** 就能加入。有裝電腦版的話，直接雙擊檔案就會打開 |
| **Google 同步** | 按 **用 Google 同步** 登入，卡片會存到你的 Google 雲端硬碟（只有 3D Cards 看得到的資料夾），其他裝置登入同一個帳號就會出現 |
| **公開展廳** | 按 **公開到展廳**，審核通過後所有人都看得到，大家可以按讚 |

### 公開展廳

- 用 Google 登入後可以替別人的卡片按 👍 或 👎
- 公開時只顯示你設定的 **公開名稱**，不會顯示 Google 帳號或信箱
- 送出時選 **原創**（你拍的、你做的）或 **轉載**（你分享的公開照片）
- 已公開的卡片可以隨時下架；想修改要先下架，或另存成新卡片
- 喜歡別人的卡片，可以按 **用這組參數製作**，套用同樣的鐳射和邊框，換上自己的照片
- 看到不適當的卡片，按 **檢舉**；被多人檢舉的卡片會先下架，等管理員重新審核

分享或公開的照片會加上看不見的水印，記錄上傳者的公開名稱。

## 安裝說明

### Windows

- **Microsoft Store 版**：在 Store 按「取得」即可，之後由 Store 自動更新
- **安裝檔版（.exe）**：雙擊執行，照畫面安裝。如果出現「Windows 已保護您的電腦」，按 **其他資訊** → **仍要執行**

快速鍵：`Ctrl+N` 製作卡片、`Ctrl+O` 匯入卡片檔、`Ctrl+F` 搜尋、`Ctrl+S` 儲存；看卡片時空白鍵翻面、`F` 全螢幕、`Esc` 返回。

### Mac

1. 打開 `3D-Cards.dmg`，把 **3D Cards** 拖到 **應用程式** 資料夾
2. 第一次打開如果出現「無法驗證開發者」，到 **系統設定** → **隱私權與安全性**，往下捲按 **仍要打開**

快速鍵和 Windows 一樣，把 `Ctrl` 換成 `⌘`。

### Android

1. 用手機下載 `3D-Cards.apk` 並打開
2. 第一次會問要不要允許「安裝不明來源的應用程式」，允許後按 **安裝**

### iPhone、iPad 和其他裝置：把網站加入主畫面

- **iPhone / iPad（Safari）**：按下方的「分享」→「加入主畫面」
- **Android（Chrome）**：按右上角 ⋮ →「安裝應用程式」
- **電腦（Chrome / Edge）**：按網址列右邊的「安裝」圖示

加入後從主畫面打開就像 App，沒有網路也能看你的卡片。

### 更新

- Microsoft Store 和 Google Play 的版本由商店自動更新
- 安裝檔版（Windows .exe、Mac、Android APK）打開時會檢查新版本，有的話會問你要不要更新；也可以在 **設定** → **檢查更新**
- 更新後卡片都會保留

## 常見問題

**換了手機，之前的卡片不見了？**
卡片存在原本的裝置上。回原本的裝置開啟 Google 同步，或下載卡片檔，再到新裝置匯入。

**分享連結打不開？**
連結只保留 14 天。請對方在原本的卡片再按一次分享，建立新連結。

**支援哪些瀏覽器？**
Chrome、Edge、Safari、Firefox 的近兩年版本都可以。
