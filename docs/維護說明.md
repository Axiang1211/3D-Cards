# 維護說明（給網站管理者）

這份文件是給架設和維護 3D Cards 的人看的，一般使用者不需要。

## 發布新版的 App（Windows + Android）

不需要指令，全部在 GitHub 網頁上完成：

1. 把修改過的檔案上傳到 GitHub（網站的程式改了，App 也會跟著用新的程式）
2. 到儲存庫上方的 **Actions** 分頁
3. 左邊選 **建置 App（Windows + Android）**
4. 按右邊的 **Run workflow**，在「版本號」填新的版本，例如 `1.1.0`，再按綠色的 **Run workflow**
5. 先建 Windows（約 5 到 15 分鐘），再建 Android（第一次約 20 分鐘，之後約 10 分鐘）。完成後 **Releases** 的新版本裡會有 `3D-Cards-Setup.exe` 和 `3D-Cards.apk`

版本號規則：三段數字，每次都要比上一版大。小修正改最後一段（1.0.1 → 1.0.2），新功能改中間一段（1.0.2 → 1.1.0）。如果填了已經存在的版本號，會用新的安裝檔取代那個版本的檔案。

發布後：

- 網站上的下載連結會自動指向最新版
- 已經安裝的 App，下次打開時會跳出更新提示

### Android 簽名金鑰（只需要設定一次）

Android 只允許「用同一把金鑰簽名」的 APK 更新舊版，所以每一版都要用同一把金鑰。金鑰放在 GitHub 的 Secrets 裡，不會出現在程式碼中：

1. GitHub 儲存庫 → **Settings** → 左邊 **Secrets and variables** → **Actions** → **New repository secret**
2. Name 填 `ANDROID_KEYSTORE_B64`，Secret 貼上金鑰檔的 base64 內容，按 **Add secret**
3. 再新增一個：Name 填 `ANDROID_KEYSTORE_PASSWORD`，Secret 貼上金鑰密碼

**金鑰檔和密碼一定要另外備份。** 弄丟的話，已經安裝的 Android App 就沒辦法再更新，只能請大家刪掉重裝（卡片也會跟著消失）。

## 分享功能

分享的卡片存在 Cloudflare 的 KV 儲存空間，名稱是 `SHARES`。第一次部署時 Cloudflare 會自動建立，不用手動設定。

- 分享的卡片 14 天後會自動刪除，不會一直累積佔用空間。要改天數，修改 `src/worker.js` 開頭的 `SHARE_DAYS`
- 免費方案每天可以建立約 1000 個分享連結，總容量 1 GB
- 想查看或刪除分享的卡片：Cloudflare 控制台 → **Storage & Databases** → **KV** → 選 `SHARES` 那一個

### 刪除任何人的分享（選用）

如果有人分享了不適當的內容，可以設定一組管理員密碼：

1. Cloudflare 控制台 → **Workers & Pages** → 選你的專案 → **Settings** → **Variables and Secrets**
2. 按 **Add**，Type 選 **Secret**，名稱填 `ADMIN_TOKEN`，值填一串只有你知道的長密碼
3. 之後也可以直接在上面提到的 KV 頁面找到那張卡片（鍵名是 `s:` 加上連結最後那串代碼）按刪除

## 公開展廳與審核

公開展廳的資料（帳號、卡片、讚和倒讚）存在 Cloudflare 的 D1 資料庫，名稱是 `DB`；照片存在 `SHARES`。兩個都會在部署時自動建立。

### 設定管理員（只需要一次）

1. Cloudflare 控制台 → **Workers & Pages** → 你的專案 → **設定** → **變數和祕密** → **新增**
2. 類型選 **文字**（或秘密也可以），名稱填 `ADMIN_EMAILS`，值填你用來登入的 Google 信箱（多個用逗號隔開）
3. 按 **部署**

### 審核

1. 用管理員的 Google 帳號登入網站（展廳的「用 Google 同步」，或 App 設定裡的登入）
2. 打開 `https://3dcards.app.dreamsworld.top/#/admin`（網站頁尾、App 的設定頁也會出現「審核」）
3. **待審核**：每張卡片會顯示作者名稱、信箱、送出日期和照片裡的隱形水印。按 **通過並公開**，或 **不通過**（可以寫原因，作者會看到）
4. **已公開**：可以看讚數，或 **下架並刪除**（例如有人反映版權問題）

頁面最下面的 **讀取隱形水印** 可以選任何一張照片，讀出是誰上傳的。照片被縮放或裁切過就讀不到。

## 網站設定

`public/js/config.js`：

| 設定 | 用途 |
| --- | --- |
| `siteName` | 網站名稱，顯示在左上角和卡片背面 |
| `repoUrl` | 頁面最下方「在 GitHub 查看原始碼」的連結 |
| `featured` | 首頁大卡片要放哪一張 |
| `siteUrl` | 網站的正式網址。分享連結和電腦版都會用到，換網域時要改這裡 |
| `downloadUrl` | 「下載 Windows 電腦版」的連結 |
| `apkUrl` | 「下載 Android 版」的連結 |
| `contactUrl` | 公開展廳「聯繫刪除」的連結（版權爭議） |
| `hubUrl` | 左上角「App 主頁」的連結 |
